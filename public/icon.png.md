# Icon Placeholder

For the Windows build, you'll need a `icon.png` file (256x256 or 512x512 pixels).

You can:
1. Create one using any image editor
2. Use an online icon generator
3. Or download a lock/security icon from sites like:
   - flaticon.com
   - icons8.com
   - iconfinder.com

For now, the app will use the default Electron icon during development.

To add your icon:
1. Create or download a PNG icon (256x256 recommended)
2. Save it as `public/icon.png`
3. Rebuild the app with `npm run package`
